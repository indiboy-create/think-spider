# youvision/think-spider 部署文档

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | >= 8.0 |
| ThinkPHP | ^8.0 |
| 数据库 | MySQL 5.7+ / 8.0 |
| PHP 扩展 | `mbstring`（字段截断）、`curl` 非必需、DNS 函数用于真实性校验 |

## 2. 安装组件

在 ThinkPHP 项目根目录执行：

```bash
composer require youvision/think-spider
```

本地开发时可先在 `composer.json` 中增加 path 仓库：

```json
{
    "repositories": [
        {
            "type": "path",
            "url": "../think-spider"
        }
    ]
}
```

然后执行 `composer require youvision/think-spider:@dev`。

组件通过 `extra.think.services` 自动注册 `Youvision\ThinkSpider\Service`，无需手动修改 `config/app.php`。

## 3. 复制配置文件

组件不会自动覆盖项目配置，需要手动复制：

Linux / macOS：

```bash
cp vendor/youvision/think-spider/config/spider.php config/spider.php
```

Windows：

```bat
copy vendor\youvision\think-spider\config\spider.php config\spider.php
```

配置文件内所有参数均有中文说明，按需修改即可。没有复制时会使用组件内置默认值。

## 4. 创建数据表

方式一：命令行导入

```bash
mysql -u root -p your_database < vendor/youvision/think-spider/database/spider.sql
```

方式二：使用 Navicat、phpMyAdmin 等工具执行 `database/spider.sql` 中的语句。

### 表前缀说明

模型会自动使用项目 `config/database.php` 中配置的 `prefix`。如果项目表前缀为 `tp_`，执行 SQL 前需把 `spider_visit`、`spider_stat` 改成 `tp_spider_visit`、`tp_spider_stat`。

`config/spider.php` 中的 `tables` 配置填写**不含前缀**的表名：

```php
'tables' => [
    'visit' => 'spider_visit',
    'stat'  => 'spider_stat',
],
```

## 5. 中间件注册

默认 `auto_middleware` 为 `true`，组件会自动把 `SpiderRecord` 注册为全局中间件，无需额外操作。

如果关闭了自动注册：

```php
// config/spider.php
'auto_middleware' => false,
```

则需要在项目 `app/middleware.php` 中手动添加：

```php
<?php

return [
    \Youvision\ThinkSpider\Middleware\SpiderRecord::class,
];
```

> 自动注册与手动注册只能二选一，同时启用会导致同一请求重复写入。

## 6. 验证部署

执行配置自检命令：

```bash
php think spider:check
```

命令会输出统计开关、数据库连接、数据表名、每个引擎的启用状态与规则数量，并检查两张数据表是否可访问、输出今日统计。如果数据表报错，请先完成第 4 步。

模拟蜘蛛访问：

Linux / macOS：

```bash
curl -A "Mozilla/5.0 (compatible; Baiduspider/2.0; +http://www.baidu.com/search/spider.html)" https://www.example.com/
```

Windows PowerShell：

```powershell
curl.exe -A "Mozilla/5.0 (compatible; Baiduspider/2.0; +http://www.baidu.com/search/spider.html)" https://www.example.com/
```

查询数据库：

```sql
SELECT * FROM spider_visit ORDER BY id DESC LIMIT 10;
SELECT * FROM spider_stat WHERE stat_date = CURDATE();
```

正常情况下 `spider_visit` 会新增一条 `spider = baidu` 的记录，`spider_stat` 当日的 `pv` 增加 1。

> 如果项目开启了页面缓存、CDN 全站缓存或静态化，请求可能不经过 ThinkPHP 中间件，蜘蛛访问不会被统计。

## 7. 配置说明

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `enable` | `true` | 统计总开关，关闭后中间件不记录任何访问 |
| `auto_middleware` | `true` | 是否自动注册全局中间件 |
| `site_id` | `0` | 站点 ID；多站点项目可传闭包，参数为 `think\Request` |
| `connection` | `''` | 数据库连接名，留空使用默认连接 |
| `tables.visit` | `spider_visit` | 访问明细表名，不含前缀 |
| `tables.stat` | `spider_stat` | 日统计表名，不含前缀 |
| `log_visit` | `true` | 是否记录访问明细；关闭后无法统计 UV |
| `stat_daily` | `true` | 是否维护日统计表 |
| `unique_uv` | `true` | 是否按 IP 去重统计 UV；关闭后 UV 恒为 0 |
| `record_methods` | `['GET','HEAD']` | 需要统计的请求方法，留空表示不限制 |
| `only_paths` | `[]` | 只统计匹配的路径，支持 `*` 通配 |
| `ignore_paths` | `[]` | 忽略的路径，支持 `*` 通配 |
| `ignore_ips` | `[]` | 忽略的 IP，精确匹配 |
| `verify.enable` | `false` | 是否开启蜘蛛真实性校验 |
| `verify.cache_ttl` | `86400` | 校验结果缓存秒数 |
| `verify.check_forward` | `true` | 是否对主机名做正向解析验证 |
| `verify.discard_unverified` | `false` | 校验失败时是否丢弃记录 |
| `verify.hosts` | 见配置文件 | 各引擎允许的主机名后缀 |
| `spiders.{key}.enable` | `true` | 是否启用该引擎 |
| `spiders.{key}.name` | 中文名 | 统计展示名称 |
| `spiders.{key}.extra_patterns` | `[]` | 追加 UA 正则，需带定界符 |
| `spiders.{key}.mobile_patterns` | `[]` | 追加移动端 UA 正则 |
| `spiders.{key}.version_pattern` | `''` | 版本提取正则，留空使用内置规则 |
| `clean.keep_days` | `90` | `spider:clean` 默认保留天数 |
| `debug` | `false` | 开启后写入异常会记录到应用日志 |

### 配置生效核实

修改 `config/spider.php` 后执行：

```bash
php think spider:check
```

确认输出与修改一致。生产环境如启用了 OPcache，修改配置后需重载 PHP-FPM 或重启 Web 服务。

## 8. 数据表字段

### 8.1 spider_visit（访问明细表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigint unsigned | 主键 |
| `site_id` | int unsigned | 站点 ID，多站点隔离 |
| `spider` | varchar(32) | 蜘蛛标识：`baidu`、`google`、`sogou`、`bing`、`shenma`、`toutiao`、`360`、`yandex` |
| `spider_name` | varchar(50) | 蜘蛛名称 |
| `version` | varchar(20) | 蜘蛛版本号 |
| `mobile` | tinyint(1) | 是否移动端：0 否，1 是 |
| `user_agent` | varchar(1000) | User-Agent |
| `ip` | varchar(45) | 访问 IP，兼容 IPv6 |
| `ip_hash` | char(32) | IP 的 MD5，用于 UV 去重 |
| `url` | varchar(1000) | 完整访问 URL |
| `path` | varchar(255) | 访问路径，不含域名与查询参数 |
| `host` | varchar(255) | 访问域名 |
| `referer` | varchar(1000) | 来源地址 |
| `method` | varchar(10) | 请求方法 |
| `status_code` | smallint unsigned | HTTP 响应状态码 |
| `visit_date` | date | 访问日期 |
| `visit_hour` | tinyint unsigned | 访问小时，0-23 |
| `verified` | tinyint(1) | 真实性校验：0 未通过，1 通过 |
| `created_at` | datetime | 创建时间 |

索引：

- `idx_spider_date (spider, visit_date)`：按引擎按日查询
- `idx_site_date (site_id, visit_date)`：多站点按日查询
- `idx_date_ip (visit_date, ip_hash)`：UV 去重
- `idx_date_path (visit_date, path(191))`：按路径查询

### 8.2 spider_stat（日统计表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigint unsigned | 主键 |
| `site_id` | int unsigned | 站点 ID |
| `spider` | varchar(32) | 蜘蛛标识 |
| `stat_date` | date | 统计日期 |
| `pv` | int unsigned | 当日访问量 |
| `uv` | int unsigned | 当日独立 IP 数 |
| `mobile_pv` | int unsigned | 当日移动端访问量 |
| `first_visit_at` | datetime | 当日首次访问时间 |
| `last_visit_at` | datetime | 当日最后访问时间 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

唯一索引 `uk_site_spider_date (site_id, spider, stat_date)` 保证每个站点、每个引擎、每天只有一条统计记录。

## 9. 统计调用

### 9.1 Facade

```php
use Youvision\ThinkSpider\Facade\Spider;

// 今日全部引擎统计
$today = Spider::stat();

// 指定日期
$day = Spider::stat('2026-11-06');

// 指定站点
$site = Spider::stat('', 1);

// 单个引擎
$baidu = Spider::get('baidu')->stat();
$baiduTrend = Spider::get('baidu')->trend(7);

// 全部引擎近 30 天趋势
$trend = Spider::trend(30);
```

`Spider::stat()` 返回结构：

```php
[
    'date'  => '2026-11-07',
    'total' => ['pv' => 128, 'uv' => 96, 'mobile_pv' => 32],
    'spiders' => [
        'baidu' => [
            'spider'    => 'baidu',
            'name'      => '百度蜘蛛',
            'date'      => '2026-11-07',
            'pv'        => 60,
            'uv'        => 45,
            'mobile_pv' => 12,
        ],
        // ...
    ],
]
```

`Spider::get('baidu')->trend(7)` 返回结构：

```php
[
    'spider' => 'baidu',
    'name'   => '百度蜘蛛',
    'days'   => 7,
    'items'  => [
        ['date' => '2026-11-01', 'pv' => 60, 'uv' => 45, 'mobile_pv' => 12],
        // ...
    ],
]
```

> `total.uv` 为各引擎 UV 之和，同一 IP 访问多个引擎时会分别计数。

### 9.2 控制器示例

```php
<?php

namespace app\controller;

use Youvision\ThinkSpider\Facade\Spider as SpiderFacade;

class Spider
{
    public function index()
    {
        return json(SpiderFacade::stat(
            (string) request()->param('date', ''),
            request()->has('site_id') ? (int) request()->param('site_id') : null
        ));
    }

    public function baidu()
    {
        return json(SpiderFacade::get('baidu')->stat((string) request()->param('date', '')));
    }

    public function trend()
    {
        return json(SpiderFacade::trend((int) request()->param('days', 7)));
    }
}
```

### 9.3 各引擎独立统计方法

| 引擎 | 类 | `stat()` | `trend()` |
| --- | --- | --- | --- |
| 百度 | `Spider\Baidu` | 支持 | 支持 |
| Google | `Spider\Google` | 支持 | 支持 |
| 搜狗 | `Spider\Sogou` | 支持 | 支持 |
| Bing | `Spider\Bing` | 支持 | 支持 |
| 神马 | `Spider\Shenma` | 支持 | 支持 |
| 头条 | `Spider\Toutiao` | 支持 | 支持 |
| 360 | `Spider\Qihoo` | 支持 | 支持 |
| Yandex | `Spider\Yandex` | 支持 | 支持 |

也可以直接实例化：

```php
use Youvision\ThinkSpider\Spider\Baidu;

$baidu = new Baidu();
$baidu->match($userAgent);
$baidu->version($userAgent);
$baidu->mobile($userAgent);
$baidu->stat();
$baidu->trend(30);
```

## 10. 多站点统计

方式一：固定站点 ID

```php
'site_id' => 1,
```

方式二：按请求参数动态解析

```php
'site_id' => function (\think\Request $request) {
    return (int) $request->param('site_id', 0);
},
```

方式三：按域名解析

```php
'site_id' => function (\think\Request $request) {
    return (int) cache('site_id_' . $request->host(), 0);
},
```

统计时传入第二个参数即可按站点筛选；传 `null` 表示不限制站点。

## 11. 历史数据清理

手动清理 90 天以前的数据：

```bash
php think spider:clean --days=90
```

也可以直接执行，使用配置中的 `clean.keep_days`：

```bash
php think spider:clean
```

Linux 定时任务（每天凌晨 3 点）：

```cron
0 3 * * * cd /www/wwwroot/your-project && php think spider:clean --days=90 > /dev/null 2>&1
```

Windows 计划任务：程序填 `php.exe` 路径，参数填 `think spider:clean --days=90`，起始位置填项目根目录。

建议访问量大的站点保留 30-90 天明细；日统计表数据量小，可以长期保留。

## 12. 蜘蛛真实性校验

默认关闭。开启方式：

```php
'verify' => [
    'enable' => true,
    'discard_unverified' => false,
],
```

校验流程：

1. 对来访 IP 执行反向 DNS 解析（`gethostbyaddr`）
2. 检查主机名是否以配置的后缀结尾（如 `.baidu.com`、`.googlebot.com`）
3. 可选正向解析主机名，确认解析结果包含来访 IP
4. 结果按 `cache_ttl` 缓存，避免重复 DNS 查询

注意事项：

- 反向 DNS 会增加请求耗时，建议开启缓存并只在有伪造 UA 困扰时启用
- 部分国内 CDN 或代理会改写来源 IP，需确保 `request()->ip()` 能获取真实 IP
- 神马、头条、360 的反向解析记录并不稳定，开启后可能误判，建议先 `discard_unverified = false` 观察 `verified` 字段
- 校验失败但未丢弃时，明细 `verified = 0`，可定期清理

## 13. 性能与容量

- 明细表随访问量增长，建议按天/周清理，或只保留 30-90 天
- 日统计表使用唯一索引 + `inc` 原子自增，并发写入安全
- 同一 IP 当日首次访问才增加 UV，其余访问只增加 PV
- 高并发场景建议关闭 `log_visit`，只保留日统计
- 生产环境建议开启 OPcache，并确保 `spider` 相关表使用 InnoDB

## 14. 常见问题

### 统计不到蜘蛛访问

1. 执行 `php think spider:check`，确认总开关、中间件、数据表正常
2. 确认请求经过 ThinkPHP，未被 CDN、Nginx 静态缓存、页面缓存拦截
3. 确认 `only_paths` / `ignore_paths` / `record_methods` 没有过滤掉目标请求
4. 确认 UA 中包含对应蜘蛛关键字，必要时通过 `extra_patterns` 追加规则

### UV 一直为 0

检查 `log_visit` 与 `unique_uv` 是否都为 `true`。关闭明细记录后无法计算 UV。

### 表不存在或字段错误

确认已执行 `database/spider.sql`；如果项目有表前缀，确认 SQL 表名与 `tables` 配置匹配。

### 同一访问被记录多次

检查是否同时启用了自动中间件和 `app/middleware.php` 手动注册，二者只能保留一个。

### 想临时停止统计

把 `enable` 设为 `false`，无需卸载中间件。
